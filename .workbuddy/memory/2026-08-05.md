## 修复：游戏库卡片高低不齐（标签数量导致）

- 文件：`admin-dashboard/src/views/platform/GameLibrary.vue`（scoped style）。
- 根因：卡片高度由标题(1~2行)、`.game-meta-sub`(3~4项，有无「时长限制」)、`.game-tags`(标签换行) 等非固定行撑开；`.game-tags` 原为 `min-height:28px` + `flex-wrap`，标签多即换行变高。
- 改动（方案A：定额化可变行，最小改动）：
  - 标题 `h4` → `.game-title-row h4`，`-webkit-line-clamp:2` + 固定 `height:2.6em`（覆盖瀑布流与列表两种视图）。
  - `.game-meta-sub` 加 `height:42px; overflow:hidden`。
  - `.game-tags` 由 `min-height:28px` 改为 `height:46px; overflow:hidden`（配合已有 +N 折叠）。
- 封面用 `aspect-ratio:3/4` 已等高，故卡片整体等高；瀑布流自动变对齐网格。
- 备选方案B：把 `.game-waterfall` 的 `column-count` 改为 `display:grid` 等高网格（用户未要求，暂未做）。
- Vite HMR 自动生效，无需重启 dev server。

## 重构：靠调整元素保证卡片等高（撤销原先的高度锁死）

- 用户反馈：原先 `height+overflow:hidden` 锁死高度会裁切内容、排版乱，要求改为**调整元素内容**让卡片自然等高。
- 元素调整（GameLibrary.vue）：
  1. 卡片只保留 1 个时间字段 = 标题下方那排「🕐 时长 X 分钟」（与详情页 `duration` 字段对齐）；移除 `.game-meta-sub` 里的第二时间字段「时长限制(timeLimitMinutes)」。

  3. 瀑布流标签文案精简为短文本（一体机/主机、联机/单机、多人/单人），保证 3 个 meta-sub 标签在 240px 卡片内单行。
- 布局：`.game-waterfall` 由 `column-count` 改为 `grid; repeat(auto-fill,240px); justify-content:start`——卡片固定宽 240、列数自适应、不拉宽。
- 撤销高度锁死：标题改单行省略(nowrap+ellipsis)、`.game-meta`/`.game-meta-sub` 改单行 nowrap（不锁高度），靠统一元素行数天然等高。
- 默认视图改列表：`viewMode` 默认 `'list'`；列表卡片排版美化（阴影/圆角/hover/垂直居中）。
