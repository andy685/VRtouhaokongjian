## 一、运营后台 · 设备管理（platform/AiShopSign.vue）

### 变更前
- 设备列表仅 4 列（ID/名称/状态/用量），无设备属性信息
- 「今日用量」弹窗为 24 小时柱状图，信息量不足
- 无 Token 复制入口

### 变更后
- 列表对齐「设备配置管理-主机管理」样式：设备编号 / 名称 / 类型 / MAC / 所属商家 / 门店 / 状态 / 最近心跳 / AI Token（截断 + 复制）
- 操作列：人设配置、Token 用量
- Token 用量弹窗升级为「近 7 天 × 24 小时」热力图（5 级色阶、悬停数值、与设备 tokenToday 对齐）

## 二、人设配置抽屉（双端同构，按角色裁剪）

### 排版
- 卡片化布局：渐变编号徽标（01–05）+ 标题 + 副标题，悬浮反馈
- 设备信息条：头像 + 设备名/ID + 在线状态 + 配置版本
- 说明文案改为轻量左线注脚（去除负边距与底色块，消除重叠）

### 字段（平台端）
| 区块 | 内容 |
|------|------|
| 身份信息 | 数字人名称、语音唤醒（锁定关闭） |
| AI 资源 | voiceId 下拉（取自声音复刻列表）+ **试听**（浏览器语音合成） |
| 知识库与业务路由 | Brand：百炼知识库多选 + **指定文章（可选）**；Store：关键词条目；Campaign：关键词条目 |
| 对话策略 | 系统提示词、问候语（多条随机）、拒答策略、能力清单、空闲搭话（时长 + 多话术） |
| 引导话题 | 话题池（预设 8 条默认 + AI 推荐），固定展示 3 个、轮换抽取 |

### 知识权限模型（重要）
| 内容 | 维护方 | 门店可见 |
|------|--------|----------|
| Brand 百炼知识库/文章 | 平台 | ❌ |
| Store/Campaign 知识条目（关键词+回答） | **店铺日常维护**，平台兜底 | ✅ |
| 命中规则 | 条目关键词优先回答 → 未命中走百炼向量检索 | — |

商家端不渲染：身份信息、AI 资源（voiceId）、Brand 知识库、系统提示词、拒答策略、能力清单。

### 保存机制
- 商家保存仅写入问候语/话题/空闲搭话/知识条目字段，平台保存全量
- 记录 `lastEditedBy`（merchant/platform）+ `lastEditedAt`，configVersion 双端同步递增
- 旧格式数据（单条问候语、逗号分隔文件 ID、Enabled/Disabled 枚举）打开时自动归一化
