## 业务链路速览

作为官方运营，你的操作是整个平台的起点。你的每步操作会驱动商家和玩家的下游流程：

```
①新建商家 → ②新建店铺 → ③录入游戏 → ④录入主机+生成Token → ⑤录入头显+绑定
    ↓              ↓              ↓                    ↓                     ↓
 商家获得后台   店铺上线营业   游戏入库上架       PC点播系统可激活       VR设备就绪
    
⑥内容分发（推送到门店） → ⑦配置拉卡拉（开通支付）
         ↓                          ↓
   门店自动下载游戏              支持微信/支付宝收款
         
         ↓ 商家侧后续流程
   ⑧商家登录后台 → 设设备密码 → 配商品价格 → 创建会员/优惠券
         ↓
   ⑨PC点播系统配置Token → 自动下载游戏 → 玩家到店体验
```

## 1. 角色定位与工作台

### 你的职责

作为官方运营，你负责：
- **商家管理**：审核入驻、开通商家后台
- **店铺管理**：为商家创建门店
- **内容管理**：录入和管理VR游戏库、审核CP上传的游戏
- **设备管理**：录入主机和头显、生成Token、绑定设备
- **内容分发**：把游戏推送到指定门店
- **支付配置**：开通拉卡拉支付
- **全局监控**：查看全平台数据、处理财务结算

### 登录工作台

1. 打开总运营后台地址，输入平台超管账号密码
2. 登录后进入「**大屏看板**」，查看全平台数据总览：订单数、营收、活跃设备、会员增长
3. 左侧菜单可访问所有管理模块

## 2. 新建商家

> **路径**：左侧菜单 → 店铺管理 → **商家管理** → 点击「新增商家」

商家是平台中的经营主体，每个商家拥有独立的商家后台。创建流程分三步：

### Step 1：基本信息

| 字段 | 说明 |
|------|------|
| 商家名称 | 如「恒然集团」「幻影星空」 |
| 联系人 | 商家主要负责人姓名 |
| 联系电话 | 商家联系电话 |
| 负责区域 | 深圳/广州/北京/上海/成都/杭州/武汉 |
| 对应代理商 | 如该商家通过代理商入驻，选择对应代理商 |
| 提现手续费率 | 默认 0.5%（0.005），可调整 |
| 商家状态 | **正常**（审核通过）/ 待审核 / 停用 |

### Step 2：管理员账号

| 字段 | 说明 |
|------|------|
| 管理员账号 | 商家后台登录用的用户名 |
| 管理员密码 | 商家后台登录密码 |

> ⚠️ **重要**：此账号密码需要交付给商家，用于登录商家后台和PC收银系统。

### Step 3：提现账户

| 字段 | 说明 |
|------|------|
| 开户银行 | 工商/建设/农业/中国/招商等 |
| 银行卡号 | 最多23位 |
| 开户人姓名 | 对公或对私账户姓名 |
| 身份证号 | 开户人身份证 |

> 提现账户用于商家结算打款，可创建后补充。

**完成后**：商家获得独立的后台访问权限和PC收银系统登录权限。

## 3. 新建店铺

> **路径**：左侧菜单 → 店铺管理 → **店铺列表** → 点击「新增店铺」

一个商家下可以有多个门店（如「福田旗舰店」「南山科技园店」）。

| 字段 | 说明 |
|------|------|
| 店铺名称 | 如「深圳福田旗舰店」 |
| 所属商家 | 下拉选择已创建的商家 |
| 所属区域 | 下拉选择城市 |
| 详细地址 | 门店实际地址 |
| 联系电话 | 门店联系电话 |
| 店铺状态 | **营业中** / 已打烊 / 维护中 |
| 开通支付 | 开启后生成拉卡拉支付二维码 |

**注册码**：店铺创建后自动生成，格式 `REG-XXXX-XXXX`，顾客扫码注册成为该店会员。

**注册规则**：可设置新注册用户自动赠送游戏币和预存款。

## 4. 录入游戏

> **路径**：左侧菜单 → 内容中心 → **游戏库** → 点击「添加游戏」

在游戏库中录入可供门店使用的VR游戏内容。

| 字段 | 说明 |
|------|------|
| 游戏名称 | 如「节奏光剑」「半衰期：爱莉克斯」 |
| 游戏类型 | 联机/单机 |
| 付费模式 | 按次 / 按时长 |
| 体验时长 | 单次体验分钟数 |
| 游戏豆消耗 | 每次体验消耗的游戏豆数量 |
| 推荐价格 | 平台建议零售价 |
| 运行平台 | 头显一体机 / 主机游戏 |
| 状态 | **已上线** / 草稿 / 待审核 / 已下架 |
| 供应商 | 选择CP游戏供应商 |

> 游戏还可以来自CP供应商后台自行上传，运营人员在「游戏审核」中审核通过后入库。

## 5. 录入主机设备与生成Token

> **路径**：左侧菜单 → 数据中心 → **设备配置管理** → 主机管理 → 点击「录入主机」

这是整个链路中最关键的步骤，主机是承载PC点播系统的电脑设备。

### 5.1 录入主机

| 字段 | 说明 |
|------|------|
| 主机编号 | 如 `PCT-001` |
| 主机名称 | 如「大厅主机 #01」 |
| 设备类型 | 悬浮骑兵/暗黑行者/暗黑机甲/幻影飞碟/通用主机 |
| 硬件配置 | CPU/内存/存储/显卡 |
| 系统版本 | 如 Windows 11 Kiosk v2.1 |
| MAC地址 | 网卡物理地址（必填） |

### 5.2 分配主机到店铺并生成Token

1. 在主机列表中找到该主机，点击「**分配**」
2. 选择**所属商家** → 选择**所属店铺**
3. 分配成功后点击「**生成Token**」

> 🔑 **Token是关键**：PC点播系统启动时需要输入此Token完成设备认证和绑定。一个主机一个Token，不可共用。

### 5.3 设备类型管理

同页面 Tab「设备类型」中可预定义主机/设备类型模板，方便批量录入。

## 6. 录入头显设备与绑定主机

> **路径**：左侧菜单 → 数据中心 → **设备配置管理** → 头显管理 → 点击「录入头显」

### 6.1 录入头显

| 字段 | 说明 |
|------|------|
| 头显名称 | 如「Pico 4 #01」 |
| 设备型号 | Pico 4 / Pico 4 Ultra / Meta Quest 3 等 |
| SN码 | 设备唯一序列号（必填） |
| 固件版本 | 如 v5.9.0 |
| 备注 | 补充说明 |

### 6.2 分配与绑定

1. 点击「**分配**」→ 选择商家和店铺
2. 点击「**绑定到主机**」→ 选择同店铺下在线的主机
3. 一台主机可绑定多台头显

## 7. 内容分发（游戏推送到门店）

> **路径**：左侧菜单 → 内容中心 → **内容分发**

游戏录入到平台后，需要通过「内容分发」推送到指定门店，门店的PC点播系统才会自动下载。

### 7.1 分发操作

1. 切换到「**游戏列表**」Tab
2. 找到目标游戏（状态为「未分发」），点击「**分发**」
3. 在弹窗中选择：
   - **目标店铺**：勾选需要分发到的门店
   - **分发方式**：
     - **智能分发**（推荐）：仅下发变更的构件文件，速度快
     - **全量分发**：重新下发全部文件（首次分发或修复用）

### 7.2 分发状态说明

| 状态 | 含义 |
|------|------|
| 未分发 | 游戏未被推送到任何门店 |
| 分发中 | 正在向门店推送游戏文件 |
| 已分发 | 推送完成，门店点播系统已可下载 |
| 有更新 | 游戏有新版本，可重新分发 |
| 失败 | 分发过程出错，可重试 |
| 已撤回 | 运营主动撤销了分发 |

### 7.3 查看分发详情

点击「**详情**」可查看每个店铺的分发进度。单个店铺支持独立撤回分发。

## 8. 配置拉卡拉支付

> **路径**：左侧菜单 → 平台财务 → **拉卡拉配置**

配置拉卡拉商户号、终端号和证书后，门店才能接收微信/支付宝付款。

需要为平台、商家、代理商、CP分别配置各自的商户信息，包括：
- 商户号 / 终端号 / 机构号
- 支付证书上传
- 分账比例设置

## 附录

### 常见问题

**Q：商家反馈登录不了后台？**
A：检查商家状态是否为「正常」，确认管理员账号密码是否正确。

**Q：内容分发后门店还是看不到游戏？**
A：确认分发状态为「已完成」，检查门店PC点播系统是否在线并完成Token配置。

**Q：设备怎么回收或重新分配？**
A：在设备配置管理中，找到设备点击「回收」，可解除分配后再重新分配到其他店铺。

### 术语表

| 术语 | 解释 |
|------|------|
| Token | 设备认证令牌，PC点播系统启动时用于绑定店铺 |
| 游戏豆 | 商家端运营代币，用于采购和管理游戏 |
| 游戏币 | 会员端消费代币，1:1抵扣消费金额 |
| 预存款 | 会员人民币储值余额 |
| 内容分发 | 将游戏从平台推送到指定门店 |
| RBAC | 基于角色的权限控制系统 |
| 拉卡拉 | 第三方支付服务商，处理微信/支付宝支付 |
