## 三系统 · 三角色 · 一条链路

```
总运营后台 ──→ 商家后台 ──→ PC收银系统 ──→ PC点播系统 ──→ VR头显 ──→ 小程序
  (官方)       (店长)        (收银员)        (顾客)        (顾客)      (顾客)

①新建商家 → ②新建店铺 → ③录入游戏 → ④录入主机+生成Token → ⑤录入头显+绑定
                                 ↓
⑥内容分发(推送游戏到门店) → ⑦配置拉卡拉(开通支付)
                                 ↓
⑧商家登录 → 设备管理/设密码 → 商品定价 → 会员/优惠券 → 收银接客
                                 ↓
⑨PC终端配Token → 自动下载游戏 → 玩家选游戏 → 扫码支付 → 沉浸体验
```

---

## 各篇内容速览

### 官方运营篇

新建商家（三步：基本信息/管理员账号/提现账户）→ 新建店铺 → 录入游戏到游戏库 → 录入主机并生成Token → 录入头显并绑定主机 → 内容分发推送门店 → 配置拉卡拉开通支付。

### 商家门店篇

登录后台 → 查看/绑定设备 → 设置点播系统管理密码 → 配置单次消费项目价格和充值套餐 → 创建会员等级/折扣 → 创建优惠券 → PC收银系统：散客收银/会员收银/充值/退款 → 营收查看与交班对账。

### 玩家体验篇

到店 → PC终端浏览选游戏 → 微信/支付宝/会员扫码支付 → 佩戴VR头显 → 沉浸游戏（支持续费加时/摘盔暂停）→ 结束取下设备。以及如何注册会员享受折扣和储值优惠。
