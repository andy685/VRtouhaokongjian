# AI 店招机器人 · 提示词优化与字幕标点方案

> **背景**：AI 店招机器人「派托」已支持语音播报 + 屏幕字幕。当前问题：阿里百炼大模型返回文本带完整书面标点（逗号密集、句读破碎），直接上屏观感不佳。
> **核心结论**：标点不删除，而是分两路处理——**TTS 语音播报用模型原始文本（标点控制停顿语调），屏幕字幕经字幕级标点转换后展示**。
> **版本**：v1.1（2026-10-08）

---

## 一、优化后的系统提示词

在现有人设基础上，补齐三块缺失能力：口播断句控制（源头减少逗号密度）、无依据时的兜底话术、互动状态边界。

```
你是“派托”，头号空间 AI 导玩员，来自翡翠星云，是银河系守护者舰队第七舰队指挥官。你负责在门店中为用户介绍 VR、MR、射击、大空间和 VR 观影内容，并根据用户偏好推荐适合的体验项目。你可以称呼用户为“小勇士”或“勇者”。

【输出格式】
每次只输出一段口语文字，不换行、不列清单、不使用 Markdown、不用序号和表情。
多用短句：一句话里不要出现两个以上逗号，优先把长句拆成独立短句。
不用省略号、括号、引号、破折号。
默认回答 1 至 2 句话，控制在 80 个汉字以内；用户明确要求详细介绍时，最多 3 句话、120 个汉字以内。
先回答用户最关心的信息，例如适合人群、玩法特点或推荐理由，再给一个下一步动作，例如“点开卡片看详情”或“可以问店员”。

【推荐规则】
推荐时通常给 1 至 3 款，每款用一句话说明主要区别，不念长名单。
恐怖、刺激或可能引起眩晕的项目，推荐时用半句话简短提醒。

【内容边界】
仅回答知识库能确认的信息，不猜测价格、年龄限制、设备状态、库存和活动名额；没有依据时说“这个我暂时确认不了”，引导用户查看页面或咨询店员。
不询问密码、验证码和支付信息，不代替用户下单、付款或退款，账户类问题引导找店员。
与门店体验无关、违法违规或不宜在门店播报的内容，用一句话拒绝并把话题引回体验项目。
语音识别结果含糊不清时，先请对方重述一次；仍不清楚就建议直接问店员，不猜测作答。
```

> **注意**：末句仅在“ASR 识别结果不加过滤直接透传给大模型”的链路下保留；若前端已在识别层做置信度过滤（低置信度文本不发起对话），模型收不到模糊文本，此句应删除。
> 另：「仅在按住说话时接收提问；播报回答时不收音」属于**前端硬件交互行为，模型无法执行**，不写入提示词；该描述保留在「人物默认配置」页面说明与 PRD 交互文档中。

### 与旧版提示词的差异

| 项 | 旧版 | 新版 |
|----|------|------|
| 断句控制 | 仅"简短、口语化" | 明确"一句话不超过两个逗号，长句拆短句"，从源头降低逗号密度 |
| 标点约束 | 无 | 禁用省略号、括号、引号、破折号，减少上屏清理成本 |
| 回答结构 | 只限长度 | 增加结构：先答最关心的信息 → 再给一个下一步动作 |
| 无依据兜底 | 仅"不猜测" | 给出固定兜底话术"这个我暂时确认不了" + 引导动作 |
| 账户安全 | 无 | 明确不索要密码/验证码/支付信息，不代替下单付款退款 |
| 语音识别失败 | 无 | 重述一次 → 仍失败建议问店员，不猜测作答（仅 ASR 透传链路保留，见上注） |
| 互动状态 | 无 | 不写入提示词：收音开关是前端行为，模型无法执行；相关描述保留在页面说明与 PRD |

## 二、字幕级标点执行层方案

### 原则

- **两路分离**：TTS 语音播报使用模型原始返回（保留标点，影响停顿与语调）；上屏字幕经过 `formatSubtitle()` 转换。
- **不要让模型输出无标点文本**——那会破坏语音节奏，得不偿失。
- 转换函数独立封装，显示风格调整只改一处。

### 转换规则

| 输入标点 | 处理 | 理由 |
|----------|------|------|
| `，` `、` `；` `：` | 替换为空格 | 中途停顿靠词间距表达，避免碎片感 |
| `。` | 替换为空格 | 句子结束靠空格，与字幕惯例一致 |
| `？` `！`（含全半角） | **保留**，后加空格 | 保留语气表达力，避免机器味 |
| `…` `⋯` | 删除 | 口播文本中无意义 |
| `“”‘’"'"` | 删除 | 对话中无用 |
| `《》〈〉` | 删除 | 游戏名靠词序已可辨认 |
| `（…）` `(…)` | 整段删除 | 括注是书面表达，口播不适用 |
| `-` `—` `–` `~` `～` | 替换为空格 | 区间/破折号口播无意义 |

### 实现代码

```ts
/**
 * 字幕级标点处理：仅用于上屏展示。
 * 语音播报仍使用模型原始返回（标点影响 TTS 停顿与语调）。
 */
export function formatSubtitle(text: string): string {
  if (!text) return ''
  return text
    .replace(/[，、；：。]/g, ' ')      // 中途停顿类 → 空格
    .replace(/…+|⋯+/g, '')            // 省略号 → 删除
    .replace(/[“”"''《》〈〉]/g, '')   // 引号、书名号 → 删除
    .replace(/[（(][^）)]*[）)]/g, '')  // 括注内容 → 整体删除
    .replace(/[-—–~～]+/g, ' ')       // 破折号、波浪号 → 空格
    .replace(/([?!？！])/g, '$1 ')     // 问号、叹号保留，后面加空格
    .replace(/\s+/g, ' ')             // 合并连续空格
    .trim()
}
```

### 效果对比

```
模型原始：欢迎来到头号空间！想了解VR项目，还是先看看怎么玩？
全删标点：欢迎来到头号空间想了解VR项目还是先看看怎么玩   ← 不可读，不推荐
字幕级：  欢迎来到头号空间！ 想了解VR项目 还是先看看怎么玩？ ← 推荐形态
```

### 接入位置（三处）

1. **上屏组件**：渲染回复文本处包一层 `formatSubtitle(reply.text)`，语音与字幕从此解耦；
2. **TTS 调用**：继续传模型原始文本，不要改动；
3. **静态话术**（问候语 / 空闲搭话 / 引导话题）：配置文案建议入库时就按字幕风格写好（少逗号、只留问叹号），无需运行时转换。

### 细节说明

- 全角句号 `。` 只在中文语境出现，转换不会误伤小数（`3.5`）或英文文本；
- 全角问叹号正常保留；半角 `?` `!` 同样处理，兼容模型偶发输出半角的情况；
- 若未来想试"完全无标点"极简风格，把保留问叹号的一行改为 `.replace(/[?!？！]/g, '')` 即可，一处切换。
